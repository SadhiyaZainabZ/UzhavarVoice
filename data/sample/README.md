# Sample Data

These files are small, representative examples for the UzhavarVoice agricultural assistant.

- `banana_pest_sample.md` — banana pest information sample.
- `paddy_climate_sample.md` — Tamil paddy climate information sample.
- `sample_record.json` — structured example record for testing ingestion.

## Source references

- TNAU Agritech Portal: https://agritech.tnau.ac.in/
- Local source inventory and download details: `../../DATASET.md` and `../manifest.csv`

The Markdown examples are concise summaries, not verbatim copies of the source pages. Verify source details before using them as agricultural advice.
